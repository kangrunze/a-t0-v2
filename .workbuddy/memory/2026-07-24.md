### 关键结论（已读源码核实）
- **2026-07-24 策略已由"均值回归"转向"趋势跟随"**（诊断：5min VWAP偏离后65%延续/29%回归）。
- 默认路径 `use_continuous_alpha=False`。买卖开仓真正只用 4 个条件（三层 confluence）：
  - 卖出开仓(reduce)：vwap_dev<0 + ADX>35 + KDJ死叉(K<D) + 量比>2.0；环境=未涨停封板。
  - 买入开仓(add)：vwap_dev>0 + ADX>35 + KDJ金叉(K>D) + 量比>2.0；环境=板块未退潮且未跌停。
  - 触发判定：extreme≥2 且 confirm≥1 且 总分≥3（min_rules_to_trigger=3）。confirm 强制量比>2.0 → 必须放量。
  - 平仓(is_for_pairing)：趋势反转(vwap_dev转正 / |dev|<0.2% / ADX<28) + 价格方向确认(最近2根60%同向) + 可成交。
- 生效参数：tf_adx_threshold=35, tf_vol_ratio_min=2.0, tf_trend_reverse_adx=28, tf_vwap_cross_threshold=0.002, tf_kdj_reverse_bars=2。
- 成本：round_trip=0.3%(佣金万2.5双边+印花0.05%卖出+滑点0.1%双边)。风控：单次T≤25%底仓, 每日≤4次, min_capture_spread=0.75%。
