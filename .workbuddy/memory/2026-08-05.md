## 因子体系调查（买卖点判定逻辑）
- **重要澄清**：当前回测买卖点**不是 qlib 因子驱动**。`src/at0/qlib/`（loader/adapter/dataset/model）是研究层工具（IC=0.3937 跑通），但 `ExpectedMoveEngine.set_qlib_predictions()` 无任何运行时调用，回测 `_qlib_predictions=None` 恒走 ROC(3/6/12) 统计外推。研究层与实盘层是断开的。
- 实际买卖点 = **V3 Alpha 七维度加权评分**（`use_continuous_alpha: true`）：
  - Trend 25%（score_trend G1×0.6 + RegimeEngine×0.4）/ Wave 20%（WaveEngine 波浪数 1/2/3/4+→95/72/38/0）/ Support 15%（SupportEngine 7类支撑位）/ Momentum 15%（G1 RSI/KDJ/MFI）/ Liquidity 10%（G1 量比）/ ExpectedMove 10%（ROC外推→RR）/ Risk 5%（RiskEngine ATR%+止损+时间）。
  - 组合：`alpha = clip(Σ(wᵢ·sᵢ)/Σw, 0, 100)`，权重在 `config/thresholds.yaml → signal.v3_alpha_weights`（mtime 缓存热更新，改 yaml 即生效）。
  - 开仓：alpha≥72 且 ExpectedMove RR≥2.0（L4 闸门）；平仓：alpha≥85（v3_alpha_close_threshold）或 trailing 0.25 / 止损 0.2% / Stage X≥80。
- **添加新因子**：无自动 REGISTRY，手动三步：① engines/ 建 BaseEngine 子类（name + score(bars,snap,direction) 0~100）② alpha_score.py `_get_engines()` 注册 + compute_alpha_score_v3 拼入 sub_scores ③ thresholds.yaml v3_alpha_weights 加权重。底层新特征需同步 features.py compute_reference_snapshot + models/feature_vector.py from_snapshot。
- 遗留建议：若要让 qlib 真正影响买卖点，需调 `ExpectedMoveEngine.set_qlib_predictions({(code,datetime): pred})` 注入回测/实盘（未做，待用户确认）。
